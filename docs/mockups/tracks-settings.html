NotationHero — Tracks & Settings

Both slide in from the right over a dimmed player (consistent with the Score sidebar), so you never leave the song. Tracks = the mixer + solo/mute-mine. Settings = everything configurable, grouped — including dark mode and Memory mode.

Tracks — the mixer

Quick Drums only / Minus drums (solo-mine / mute-mine, the the reference tutor idea) up top, then per-track volume with Solo (S) / Mute (M). Your own track is highlighted.

Opens from the Tracks button. "You" = whatever you chose in Settings → Input (drums by default). Solo-mine isolates your track; Minus-drums plays everything but it.

Settings — grouped, on demand

A sectioned modal. Showing Input & MIDI; the other tabs hold timing windows, practice modes, and display/theme. This is where dark mode lives (per your note) and where Memory mode is armed before play.

Opens from the Settings cog. Left tabs = the full settings map; each is a short, scannable group (no wall of options).
