NH-221 · SD-31 — pattern routes use the kind (done).
A pattern's route reflects its pattern_kind + its slug: #/pattern/pat_zoio_fill → #/fill/zoio-de-lula-tom-fill. In a song/lesson it carries both slugs: #/song/yellow/beat/yellow-groove-closed-hat. The umbrella route #/pattern/:id still resolves (redirects to the slug route).
Slug — every navigable playable has a friendly slug (separate from the opaque id) used in URLs; the id still resolves as a fallback.
