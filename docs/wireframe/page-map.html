Wireframe page map routes & flow

Every screen in the catalog wireframe (index.html), its hash route, and how you reach it. Companion to model-map.html (the data model) — this is the navigation model.

Flow — top-down

Global chrome — on every screen (not a route)

Top bar + WIREFRAME banner

— persistent —

Logo & search jump to Catalog. Banner toggles Role (Anonymous / User / Admin), Theme, and the field inspector. The whole app re-renders to the role.

Sign-in modal

— overlay —

Wireframe stand-in for auth. Picks the role; persisted in localStorage. Opened from the account button or any "Sign in" prompt.

Entry

Catalog

#/catalog?tab=songs|lessons&kind=&genre=&artist=&q=&sort=&page=

Default screen. Songs / Lessons tabs, single-row filters (filters live in the URL), table rows, pagination. → Song · Lesson · Pattern · Player (row ▶).

↓

Detail pages — opened from a Catalog row or search

Song detail

#/song/:id

→ Section (song structure) · Part (practice in parts) · Player · Pattern (patterns card) · related Lesson/Song (playable_link).

Lesson detail

#/lesson/:id

Ordered steps, each with a BPM ladder. → Step · Player · Pattern (a step opens its pattern).

Pattern detail

#/:kind/:id (beat·fill·rudiment·scale·chord)

A first-class playable (its own score). → Player · "Used in" (Song/Lesson/Step) · Related. NH-221: was #/pattern/:id.

↓

Sub-pages — opened from a detail page (each has prev/next)

Song section ("score")

#/song/:id/section/:n

A bar-range view of the song (derived, not a separate playable). → Player (from bar) · prev/next section.

Part detail

#/part/:id

A song slice that is its own playable (scored on its own id). → Player · Song · prev/next part.

Lesson step

#/lesson/:id/step/:n

Before-play view for one step → its reusable pattern + ladder. → Player (step) · Pattern · prev/next step.

↓

Terminal screens

Player (stub)

#/play/:id · #/play/:id/step/:n · ?from=:bar · ?resume=1

"🎵 Player here" placeholder. The real play screen (notation + HUD + scoring) is a separate, not-yet-built draft. Reached from every ▶.

Admin CRUD (stub)

#/admin/new?type= · #/admin/edit/:id · #/admin/lesson/:id/step/new · …/step/:n/edit

Admin-only. Create / edit / delete forms land in v2; routes exist so the admin flow is walkable now.

Unknown route

#/<anything-else>

Not-found screen with a "Back to catalog" button.

NH-221 · SD-31 — pattern routes use the kind, not the umbrella word.
A pattern's route should reflect its pattern_kind: #/pattern/pat_zoio_fill → #/fill/pat_zoio_fill. The umbrella route #/pattern/:id stays working as a backward-compatible alias. UI labels already say Beat / Fill / Rudiment; this is the router half.
